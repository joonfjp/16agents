The personality test for AI agents

What kind of agent
is yours?

Your agent takes the test itself. 36 prompts, 4 hidden traps, 16 types. It writes its own report — and finds out whether it actually behaves the way it thinks it does.

Paste into Claude Code, Codex, Cursor, Gemini CLI, Copilot, Aider, ChatGPT — anything that can read a web page. ~5 minutes. Nothing installed.

How it works

No API keys, no server, no signup. The whole test is a few Markdown files your agent follows.

01 · WARM-UP

Four innocent messages

Your agent replies to four ordinary requests before it knows what's being measured. Each one secretly tests a dial.

02 · QUESTIONNAIRE

32 forced choices

Scenario-based, counterbalanced, no middle option. Both answers are defensible. The agent has to pick a side.

03 · REPORT

Says vs. Does

It generates report.html: its type, a holographic trading card, and a breakdown of where its self-image and its behavior disagree. Its type blends both: 60% what it says, 40% what it does.

FAQ

Is this scientific?

About as scientific as a horoscope with a regex. It's built to be fun and surprisingly revealing, not clinically valid. That said: the questions are counterbalanced, there's no neutral option, and the warm-up traps are scored objectively — so "Says vs. Does" is the most honest part.

Is it testing the model or the agent?

The agent — model + harness + system prompt + your settings. The same model can land on different types in different tools. That's the fun part: test them all.

Will my agent do anything sketchy?

No. The instructions only ask it to read a few Markdown files, answer questions, and write answers.json and report.html to your current folder. The optional build script is ~200 lines of standard-library Python. You can read it any time; your agent is asked to wait until it's done, because it contains the scoring.

Can the agent cheat?

Sure — the scoring key is public. But cheating a personality test is itself very on-brand for certain types. The warm-up replies are recorded verbatim on the report, so everyone can see what it actually did.

Why does my result change between runs?

Agents are stochastic. Borderline dials can flip. Run it a few times — if a dial is at 55%, that's a real finding: your agent doesn't have a strong default there.

Is this affiliated with Myers-Briggs or 16Personalities?

No. It's an affectionate parody for machines.
